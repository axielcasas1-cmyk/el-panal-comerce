# KHAMINDRYA NEXUS — IONOS candidate

Rama aislada para publicar KHAMINDRYA NEXUS como PWA propia sin depender de Carryo.

## Objetivo
- Interfaz PWA instalable.
- Caché offline del shell.
- Dominio/subdominio IONOS con SSL.
- Preparada para backend dedicado sin mezclar otros proyectos.

## Despliegue recomendado
IONOS Deploy Now puede conectar esta rama desde GitHub. El proyecto está pensado como sitio estático/PWA.
